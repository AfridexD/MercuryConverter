Code signing policy

How the files you download are built and signed, and who is responsible for them.

Status: the current downloads are not code-signed yet. Windows may show a SmartScreen warning the first time (choose More info, then Run anyway). Signing is being set up, and this page will be updated when it is switched on.

What is signed

  • Mercury's own program files: MercuryConverter.exe, MercuryConverter.dll and Mercury.Converter.Core.dll.
  • The installer, and its uninstaller.

The converter programs inside the download (FFmpeg, ImageMagick and libjxl) are made by other projects. Mercury does not change or re-sign them. See the third-party licenses.

How files are built

Releases are built from the public source code on GitHub, by a script anyone can read: .github/workflows/release.yml. Only files produced by that build are signed. The build runs the automated tests first, and every release comes with SHA-256 checksums.

Who is responsible

  • Maintainer, reviewer and approver of releases: AfridexD.
  • Changes arrive as pull requests and are reviewed before they are merged. A release is made as a draft first, and is published only after the maintainer has checked it.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Files are converted on your own computer. The only network request the app can make is the optional update check, which is off until you turn it on. Read more about security.

Reporting a problem

If you think a signed file is wrong or has been tampered with, please send a private security report, and do not run the file.
