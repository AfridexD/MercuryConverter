Questions and fixes

Quick answers. If yours is not here, ask on GitHub.

General

Is Mercury Converter really free?

Yes. It is open source under the MIT license, with no ads, no account, no trial and no paid tier.

Are my files uploaded anywhere?

No. All conversion happens on your computer, and the app does not need the internet. It collects no usage data. You can check: the source code is public.

Does it change my original files?

Never. Mercury reads the original and writes a new file. It also never replaces a file that already exists: it adds a number to the name instead (photo (2).webp).

Which formats can it open and make?

See the format table on the home page. Photos include JPEG, PNG, HEIC, WebP, AVIF, JPEG XL, TIFF and camera RAW. Video includes MP4, MOV, MKV, WebM, AVI and more. Audio includes MP3, M4A, FLAC, WAV, OGG and more.

Is there a Mac, Linux or phone version?

Not at the moment. Mercury Converter is for Windows 10 and 11 only.

Is there a dark mode, or other languages?

Not yet. The app is light-themed and in English. Both are planned.

Windows warnings

Windows says "Windows protected your PC". Is it safe?

SmartScreen warns about any new program that few people have downloaded yet and that is not code-signed. Code-signing certificates cost money each year, and Mercury does not have one yet. The warning does not mean the file is bad.

To run it: choose More info, then Run anyway. To be extra careful, compare the file's checksum with the one on the release page. In PowerShell: Get-FileHash .\MercuryConverter-x64-setup.exe. The two long strings should match.

My antivirus flagged something.

Mercury includes FFmpeg, ImageMagick and libjxl, which some antivirus programs treat with suspicion because they are powerful tools that unsigned programs also use. If you want certainty, build Mercury yourself from the source code.

Right-click menu

I do not see "Mercury Converter" when I right-click.
  • Open Settings and make sure Show in the right-click menu is On.
  • On Windows 11, the menu is under Show more options. You can also hold Shift while you right-click.
  • The menu only appears on file types Mercury can read, such as JPEG, MP4 or MP3.
  • If you moved the app's folder, open Mercury once. It repairs the menu so it points to the new place.
The app opened from the menu but my file was not there.

Early test builds had this problem: Windows did not pass the file name to the app. It is fixed in the 1.0.0 release. Install the latest version, open it once so the menu repairs itself, and try again. If it still happens, tell us which kind of file it was.

Can I choose which formats appear in the menu?

Not yet. The menu lists the common formats for each kind of file, in a fixed order.

Why does selecting many files open the main window?

The small window is for one file. With several, the main window can show every file's progress at once.

Results and sizes

My converted file is bigger than the original.

It can happen when a file is already very compact. Mercury tries lower quality settings when Never make a file larger than the original is on, but some files cannot be made smaller. Going to GIF is the usual cause: GIF is an old format and its files are much larger than video. Try MP4 or WebM instead, or lower the quality slider.

The picture looks worse than the original.

Raise the Quality slider, or choose a format that loses nothing: PNG for photos, FLAC for audio. Converting an already-compressed file again always loses a little.

Where did my converted files go?

Next to the originals, unless you chose another folder under Save to. Open any finished card's ⋯ menu and choose Show in folder, or use Show in folder in the green bar after a run.

A file says "Failed".

Open its ⋯ menu and choose Details for the reason, then try Retry (F5). Common causes: the file is damaged or only partly downloaded, the disk is full, or another program has the file open. For a damaged video, the Quick Convert window can offer to save the part that is readable.

Does converting video to MKV keep subtitles and audio tracks?

Yes. MKV output keeps every audio track and subtitle track.

Does a GIF keep its animation?

Yes, GIF to GIF stays animated. GIF to MP4 or WebM makes a video of the animation.

Speed and your PC

Conversion is slow, or it makes my PC slow.

Open Settings and change Speed. Gentle keeps your PC responsive. Balanced (the default) adapts to what else you are doing. Fastest uses everything. Video is the heaviest job, so large videos take the longest whatever you pick.

Should I turn on "Encode video on the graphics card"?

Only if you care more about processor use than file size. It works with NVIDIA, AMD and Intel graphics, but the files come out about 60% larger. It is off by default. Mercury already uses your graphics card to read video faster, with no extra size.

Where does Mercury keep its settings?

In %LOCALAPPDATA%\MercuryConverter: your settings, presets and a cache of previews. Delete that folder to start fresh. Previews are cleaned up automatically and use at most about 200 MB.
